About

I'm James Applewhite, a data analyst working toward data engineering, and a casual data science liker. A pipeline that ends as a few database tables nobody sees isn't much fun, so this site is where my projects show up: scheduled jobs load the data, and these pages put it in front of people.

The web app itself is a hobby. My focus is the data, but I enjoy building the place where it lands. The first page here was a Wordle solver in October 2022, and the solvers have kept coming since.

Building tools for people I'll never meet has convinced me that UX matters. Nobody is there to walk them through it, so the page itself has to show how it works, and it has to be easy to use. My shorthand when I build is "1 click is unfortunate, 2 clicks is a tragedy." It's an exaggeration, but it keeps me honest about friction.

Projects

The Magic: The Gathering price tracker runs on a daily AWS pipeline that follows about 100K cards for under $1 a month. It has its own repo and Streamlit dashboard, and a bot posts the day's biggest price changes to Bluesky.

YouTube Trending pulls the day's trending videos from the YouTube Data API into MySQL and shows 30-day trends by category.

The site also tracks its own traffic and health, and the code for all of it is on GitHub.

I also built a private tool for dialing in espresso. I log each shot, and a k-nearest-neighbors model recommends the settings for the next one.

The site

Everything here is free, and there are no accounts. Ads help pay for hosting, and the Privacy Policy covers what the site keeps.
