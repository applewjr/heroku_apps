Remove/Allow Words

Remove takes a word off the solver's suggestions. Allow keeps a word on them that the solver would leave out as a plural or other -s form (a real word that only looks like one), and player reports can't take it off. Your entries are final: players can never reverse them, and the word's votes start over. Type the word, choose, then press Submit.

Player Reports, last {{ crowd_window_days }} days

Players have no way to report words on /chainle, so this tab stays empty. Remove and Allow above still steer the solver.

A word comes off once enough different players report it - the rarer the word, the fewer it takes: {% for floor, needed in crowd_remove_bands %}{{ needed }} at popularity {{ floor }} or above, {% endfor %}{{ crowd_remove_rare }} below that or none. Needed is that number for each word. Players counts every report in the window, including ones from a player over the daily limit, which don't count toward a removal. Either button clears that word's votes.
