Frequently Asked Questions

How do I search for words by pattern?

Use the pattern field with wildcards. An asterisk (*) matches any run of letters and a question mark (?) matches exactly one letter. For example, c?t matches cat, cot, and cut, while pre* matches every word starting with pre. The SQL LIKE characters % and _ work too.

Can I find words that start with or end with certain letters?

Yes. Type into the Starts with and Ends with fields to require an exact prefix or suffix, and combine both to pin down words that begin one way and end another.

What is the difference between Contains text and Must include letters?

Contains text looks for an exact string of letters in a row, like tion. Must include letters only checks that each letter appears somewhere in the word, in any order and any position.

Is this word finder free?

Yes, it is completely free with no signup required. Results update instantly as you type.
